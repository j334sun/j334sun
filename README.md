## Featured project

### [Life Expectancy: Comparing Mixed-Effects Models](https://github.com/j334sun/life-expectancy-mixed-effects)

An independent STAT 437 project using **2,864 observations from 179 countries** to compare multiple linear regression, linear mixed-effects models, mixed-effects regression trees, and mixed-effects random forests.

- **Statistical modelling:** account for repeated observations within countries and compare linear and tree-based approaches.
- **Evaluation:** compare cross-validation error across global and regional subsets, supported by residual diagnostics.
- **Critical interpretation:** explain why row-level validation does not establish performance on unseen countries or future years.
- **Tools:** R, R Markdown, `nlme`, `rpart`, `randomForest`, and `ggplot2`.

[Read the analysis and results →](https://github.com/j334sun/life-expectancy-mixed-effects#results-from-the-original-analysis)
